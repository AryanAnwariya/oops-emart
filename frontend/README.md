# E-Mart Frontend

React frontend application for E-Mart

## Setup Instructions

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Features

- React 18
- Vite build tool
- React Router for navigation
- Axios for API calls
